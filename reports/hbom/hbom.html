Scope and Limitations

This report represents hardware visible inside an AWS EC2 virtual machine. It does not represent the complete physical AWS host inventory. Scanner-generated bridge entries and host-specific identifiers have been excluded. This report is an inventory, not a hardware vulnerability assessment.
